# 📓 Notebook - AI Note Summarizer

Notebook is a secure, full-featured note-taking platform powered by the MERN stack. It integrates powerful AI-based summarization capabilities, making note management smarter, faster, and more organized for students, professionals, and teams.

---

## 🚀 Features

- 📝 Create, edit, and delete notes
- 🔐 User authentication with secure login/signup
- 🤖 AI-powered note summarization (via Gemini API)
- 🧠 Smart suggestions for titles and tags
- 🔎 Full-text search and filtering
- 📁 Organized note categorization and tagging
- ☁️ Cloud-based, real-time data sync with MongoDB
- 📱 Responsive UI built with React + Tailwind CSS
- 🎨 Dark/light mode support
- 🔔 Email notifications on note activities (NodeMailer, SES)

---

## 🧰 Tech Stack

- **Frontend**: React, Tailwind CSS, React Router, Axios
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas
- **AI Integration**: Gemini API for text summarization
- **Authentication**: JWT & bcrypt
- **Email Service**: NodeMailer / Amazon SES
- **Deployment**: Vercel (frontend), Render/Heroku (backend)
